# Game Brief: UNI-VERSE : 인천대 정복 RPG

**One-sentence pitch:** 도서관에서 앱을 켜두고 공부하는 시간이 그대로 내 횃불이 캐릭터의 경험치와 골드가 되는, 인천대생을 위한 16-bit 방치형 RPG.

## Core loop
- 앱을 켜두고 공부(방치)한다 → 시간에 따라 경험치·골드가 쌓인다
- 골드로 장비를 강화하고 잠재능력 3줄을 리롤한다 → 획득 효율이 오른다
- 과제(퀘스트)를 완료한다 → 대량 보상을 받는다 → 다시 방치한다

## Player goal & fail state — what "working" looks like
- **목표**: 레벨을 올리고 장비 잠재능력을 원하는 옵션으로 맞추는 것. 공부를 마치고 앱을 다시 열었을 때 쌓인 보상을 받고, 강화를 한 번 이상 하면 한 세션이 끝난다.
- **실패 상태**: 마감일이 지난 과제 퀘스트는 "실패"로 표시되고 보상을 받을 수 없다.

## MVP — what must exist to be the game
1. **유니 테스트**: 5문항으로 6개 직업 중 하나를 배정하고, 기존 캐릭터 PNG를 보여준다.
2. **방치 파밍**: 켜둔 시간과 자리를 비운 시간만큼 경험치·골드가 오르고, 레벨이 오른다.
3. **장비 4부위**: 전공책, 노트북, 텀블러, 백팩을 골드로 강화하고 잠재능력 3줄을 리롤한다.
4. **퀘스트 목록**: 샘플 과제(과목명, 과제명, 마감일)를 RPG 문구로 보여주고, 완료하면 보상을 받는다.
5. **직업 스킬**: 직업마다 고유 스킬 1개가 획득량에 적용된다. 예: 은둔형은 01~05시에 경험치 +30%.
6. **저장**: 브라우저 localStorage에 진행 상황을 저장한다.

## Out of scope — not building this
- LMS(.ics) 실제 연동과 Claude API 퀘스트 변환 (데모에서는 샘플 데이터만 사용)
- 학과 길드, 점령전, GPS 체크인, 길드 연구소 기부
- 학점 펫, 유물 가챠, 보스전
- 로그인, 서버 DB, Vercel API

## Build order
1. 방치 루프와 저장: 게임의 핵심. 이게 재미없으면 나머지도 의미가 없다.
2. 장비 강화와 잠재능력 리롤: 골드를 쓰는 곳이자 도파민의 핵심.
3. 유니 테스트와 직업 스킬
4. 퀘스트 목록 (샘플 과제)

---
**Who it's for / what they feel:** 시험 기간의 인천대생. "내 공부가 내 캐릭터를 강하게 만든다"는 성취감.

**Art & audio direction:** 횃불이 기반 64x64 도트, 16-bit 레트로 JRPG UI. 데모에서는 사운드 없음.

**Reference game:** 메이플스토리. 잠재능력 3줄 리롤의 도파민만 가져오고, 사냥과 맵은 뺀다.
